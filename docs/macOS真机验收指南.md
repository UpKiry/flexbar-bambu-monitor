# macOS 真机验收指南

正式运行时使用 Node 云连接，无需安装 Python。具体验收范围与待完成项以 [验证状态](验证状态.md) 为准；字段及状态规则见 [设备协议与状态模型](设备协议与状态模型.md)。

## 构建及安装

在本项目目录使用 Node.js 20，先执行：

```sh
npm install
npm test
npm run build
npm run plugin:validate
npm run plugin:pack
```

使用生成的 `.flexplugin` 文件按 FlexDesigner 的安装方式安装，或在确认 FlexDesigner 已安装后运行 `npm run plugin:install`。此命令使用 `--force`，会覆盖本机同 UUID 的已安装插件；如需保留旧版本，请先自行备份。构建输出是本机验收候选，并不证明签名、公证、跨架构兼容或最终分发方案已完成。

## 验收步骤

1. 在 FlexDesigner 中打开 Bambu Monitor 设置，选择「进入后台」。如浏览器未自动打开，使用设置页给出的本机地址。仅在本机页面输入账号密码或验证码，不要将这些信息发给开发者。
2. 在后台选择中国大陆账号区域并登录。按服务端提示完成验证码；确认绑定设备列表，选择 A1。若没有设备或连接失败，记录页面上的错误类别，不要导出或发送任何原始云响应。
3. 等待设备状态。确认连接状态和最近报文时间；检查任务名、进度、剩余时间、层数、温度、故障原始码及 AMS 各槽位颜色、材质、余量和原始状态是否符合设备实际。未上报项显示未知或空，0 不应被当成未知；颜色、余量及状态含义以设备实际为准。
4. 观察空闲、打印及自然发生的任务切换；在方便时断开网络再恢复，确认断线后的字段标记为旧，局部报文只刷新其中实际更新的字段。有效遥测持续活跃超过五分钟时，未被标旧的稳定字段仍沿用原观测时间；断线前未重新上报的字段继续标旧。不要为了验收制造故障；如自然出现故障，只记录可见原始码和界面表现。
5. 将监控按键添加到 Flexbar，确认状态绘制、点击切换视图和中文显示；修改设备选择后重启宿主，检查非敏感配置是否保留。测试登录状态是否从系统钥匙串恢复；钥匙串不可用时页面会提示仅在内存保存，需要重新登录。
6. 分别观察打印机上下线事件和插件断网：明确断开显示离线、连接后等待同步、云端中断显示未知，120 秒无有效遥测显示无响应；不要将无响应当成关机。等待同步或无响应时自动恢复最多两次，间隔至少五分钟，重连不重置预算，有效遥测重置；核对休眠/稳定上报时是否误判。仅在需要时点击完整状态查询。请求是只读 `pushall`，同一设备两次请求间隔至少 5 秒；为避免影响打印机响应，请勿短时间内反复请求。提交成功不代表打印机已收到请求。
7. 测试退出登录。旧版本可能遗留系统钥匙串条目；若退出提示操作失败，可在「钥匙串访问」检查服务 `com.upkiry.bambumonitor`、账户 `bambu-cloud-token` 的旧条目并自行删除。不要分享条目内容。

如需反馈，请提供 macOS、FlexDesigner、插件版本、A1 固件版本、验收步骤、发生时间及不含敏感信息的页面现象。不要提供密码、验证码、令牌、设备接入码、完整设备报文或原始账号响应。诊断导出也应在分享前自行检查。

将实际执行的项目、候选标识和观察结果写入 [验证状态](验证状态.md)；未执行项目保留待验收，不以安装成功代替通过。
