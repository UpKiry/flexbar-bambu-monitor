# Bambu Monitor v0.7.1

修复 Flexbar 进度条上方百分比数字消失、只剩 `%` 的问题。

## 修复

- 将进度数字改为宿主 Canvas 正常支持的字重，避免异常字宽触发裁切，恢复进度百分比显示。
- 排查其他 Canvas 文字绘制位置，未发现其他同类字重问题。
- 增加零进度、中间进度、100% 与旧数据标记的回归覆盖。

## 安装

下载附件 `com.upkiry.bambumonitor.flexplugin`，在 FlexDesigner 中覆盖安装。需要 FlexDesigner 1.3.0+ 和 Flexbar。

## 验证

- Node.js 20 下 419 项测试、生产构建、插件目录校验与打包通过。
- 使用 FlexDesigner 内置 Canvas 离线验证 10 帧及 14 种字体样式。
- macOS / Flexbar 安装修复后，用户确认进度数字恢复显示。

本版本延续 v0.7.0 的只读监控功能。详细功能见 [v0.7.0 发行说明](https://github.com/UpKiry/flexbar-bambu-monitor/releases/tag/v0.7.0)。
