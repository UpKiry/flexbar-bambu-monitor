# Bambu Monitor v0.7.0

面向日常使用的 Flexbar 只读监控版本，集中改进长条界面、刷新反馈与设备状态判断。

## 新界面

- 石墨黑底与薄荷绿进度，2170 × 60 长条集中展示任务、层数、进度、剩余时间、温度、风扇与 AMS。
- 按机型能力和实际读数展示；AMS 显示实际单元/槽位 ID、颜色、材质及允许展示的余量，AMS lite 隐藏余量。
- 长文本按实际字宽截断，旧值逐项标记；原始错误码与 HMS 优先展示，历史故障明确区分。

## 交互与连接

- 屏幕触摸请求完整状态，结果直接显示在任务名一行，随后恢复任务名，避免原生弹窗与整屏刷新叠加。
- 合并短时间内重复触摸，保留每台打印机五秒手动查询冷却。
- 分开维护云端连接、设备在线状态和打印活动；区分等待同步、明确离线、无响应和未知，断线保留最后读数。
- 字段缺失保留旧观测、null 清空、零值有效；持续有效遥测不会让稳定读数仅因单字段年龄而被误标旧。
- 统一安排连接补全、在线字段补全、失活恢复和低频兜底，设间隔与重试预算；重连不绕过预算。
- 后台显示设备列表快照时间、消息到达时间和有效遥测时间；只有原始 AMS 状态的报文不作为在线证据。

## 安装

下载附件 `com.upkiry.bambumonitor.flexplugin`，在 FlexDesigner 中安装或覆盖更新。需要 FlexDesigner 1.3.0+ 和 Flexbar。插件设置中进入本机后台，选择账号区域、登录并选择打印机，然后打开「打印机状态」。

## 内部结构

- 设备连接统一由设备注册表收敛：默认设备与按键指定的其他设备共用建连、幂等与关闭屏障，账号失效只保留一个处理入口。
- 按键、视图、绘制节流、Direct Draw 会话与触摸反馈窗口移出应用编排，拥有独立模块和测试。
- 展示层、Direct Draw 与浏览器后台共用同一份观测时效规则，120 秒活跃窗口、五分钟兼容回退与 AMS 空槽保护分别定义。
- 设备管理器发布只读状态快照，调用方无法绕过合并逻辑修改状态。
- AMS 数值与时效在同一模块按同一补丁更新。
- 浏览器后台源码拆分并随生产构建打包；页面测试改为模块接口调用。

以上为内部调整，不改变云接口、配置字段与只读边界。

## 验证与边界

- 发布前执行 Node.js 20 全量测试、生产构建、插件目录校验和打包；macOS / A1 + AMS 只读监控及更新后总体体验已有用户确认。
- 云接口和设备字段会随固件与服务变化；自动恢复阈值、多机型边界、Windows 与异常路径仍需逐项验证。Windows 暂未实现凭据持久化。
- 插件仅提供只读监控和完整状态查询，不包含打印控制或摄像头。

详细验证记录见[验证状态](https://github.com/UpKiry/flexbar-bambu-monitor/blob/v0.7.0/docs/验证状态.md)，字段与恢复规则见[设备协议与状态模型](https://github.com/UpKiry/flexbar-bambu-monitor/blob/v0.7.0/docs/设备协议与状态模型.md)。
