## 文档职责

- 开发指南定义目录、编码/安全、开发与测试流程。
- 架构设计定义组件如何协作；协议文档定义字段、计时和状态如何解释。当前规则只在对应专题完整定义，其余位置链接引用。
- 验收指南定义“如何测”，验证状态定义“实际测过什么、还缺什么”。不将构建成功或模拟报文当作真机通过。
- archive 中“本轮”“当前”和测试数量均属于记录当时；历史规则可能已被替代，不作为现行规范。
